## 📌 About

Crypto Portfolio Tracker 2026 keeps all your holdings in one view — across chains, wallets and exchanges.
It reads public addresses only, pulls current and historical prices, and shows real-time P&L.
No private keys, no signing, no transactions.

## 🧩 Core Modules

- 🌐 Multi-chain address support
- 💹 Live price feeds from public APIs
- 📈 P&L analytics per asset and per period
- 🔔 Price alerts with custom thresholds
- 📊 Allocation charts and breakdowns
- 📄 Export to CSV, JSON
- 🎨 Dark and light themes
- 🔧 Custom RPC and API endpoints

## 🖥️ Requirements

- Python 3.10+ or Node.js 18+
- Internet connection (for price feeds)
- Windows, Linux, macOS

## 🛡️ Privacy Notes

Only public addresses are stored.
No private keys are requested at any point.
All data stays on your machine.
